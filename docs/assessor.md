# Assessor guide

Assessors should use the system in this order:

1. verify the participant's evidence;
2. assess understanding first;
3. unlock prestigiousness only after the mandatory understanding gate is complete;
4. keep technical correctness separate from customer enthusiasm;
5. record conflicts of interest and respect fulfilment visibility.

Understanding explanations list incomplete criteria explicitly. Reward explanations remain decomposed so a single popularity-style measure cannot override correctness or safety.
